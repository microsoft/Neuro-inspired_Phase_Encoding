# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Please search the
existing issues before filing new ones to avoid duplicates. For new issues, file your bug or
feature request as a new Issue.

For questions about using the code or reproducing results in the
[paper](https://arxiv.org/abs/2604.07904), please open a GitHub Issue. The maintainers will
respond on a best-effort basis.

## Microsoft Support Policy

Support for this research project is limited to the resources listed above.
